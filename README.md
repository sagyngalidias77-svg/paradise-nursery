# Paradise Nursery

Paradise Nursery is a React houseplant store with a categorized catalog and a Redux shopping cart. The cart supports adding plants, editing quantities, deleting items, and recalculating subtotals and the order total. Checkout displays a Coming Soon message.

## Run locally

```sh
npm install
npm run dev
```

Open the address printed by Vite. Use `npm run build` for a static production build.
